# Visión del proyecto

SplitUp es una aplicación destinada a facilitar el reparto de gastos compartidos entre grupos de personas de forma clara, transparente y automatizada.

El proyecto nace como Trabajo de Fin de Grado (TFG) del ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM), con el objetivo de aplicar conocimientos reales de análisis, diseño, arquitectura y desarrollo de software.

SplitUp está pensada para escenarios cotidianos como:

- Compartir gastos en un piso
- Viajes en grupo
- Comidas y eventos
- Actividades de ocio

La aplicación busca ofrecer una experiencia sencilla para el usuario, pero con una arquitectura interna sólida y escalable.
