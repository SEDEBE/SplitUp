# Requisitos del sistema

## Requisitos funcionales

- RF-01: El sistema permitirá el registro e inicio de sesión mediante Google o Facebook.
- RF-02: El usuario podrá crear y gestionar grupos.
- RF-03: El usuario podrá añadir participantes a un grupo.
- RF-04: El usuario podrá registrar gastos asociados a un grupo.
- RF-05: El usuario podrá definir quién paga un gasto.
- RF-06: El sistema calculará automáticamente el reparto del gasto.
- RF-07: El sistema mostrará balances indicando quién debe dinero y a quién.
- RF-08: El usuario podrá adjuntar imágenes de tickets a un gasto.
- RF-09: El usuario podrá consultar el historial de gastos.

## Requisitos no funcionales

- RNF-01: El sistema debe ser intuitivo y fácil de usar.
- RNF-02: La lógica de negocio debe estar desacoplada de la interfaz.
- RNF-03: El sistema debe ser escalable.
- RNF-04: El sistema debe proteger los datos del usuario.
- RNF-05: La aplicación debe funcionar en entorno desktop y Android.
